# Формат прайс-листа Auto.ru — коммерческий транспорт (грузовики/прицепы/спецтехника)

Источник: https://yandex.ru/support/autoru-legal/ru/requirements-trucks
(собрано 2026-09-11). Это ОТДЕЛЬНАЯ документация от `reference/autoru-api/`
(та описывает API личного кабинета дилера apiauto.ru; этот файл — формат
самого XML-прайс-листа, который дилер отдаёт по URL в поле `source`
настроек `/feeds/settings/...`, см. `reference/autoru-api/feeds-settings*.md`).

**Важно:** значения справочников здесь — **на русском языке** (например
`Полуприцеп-тяжеловоз`), а НЕ английские коды типа `ST_HEAVY`, которые
встречаются в `reference/autoru-api/trailer-type-dictionary.md` (тот
словарь — для другого метода API, `GET /reference/catalog/...` внутри
apiauto.ru). Для Белкара (прицепы) генератор фида должен использовать
именно русские строки из этого файла, а не ST_*-коды.

## Общие требования

- Кодировка UTF-8, заголовок `<?xml version="1.0" encoding="utf-8"?>`
- Первые 32 ASCII-символа запрещены в текстовых полях (кроме таб/перевод строки/возврат каретки)
- Обязательное экранирование: `"` → `&quot;`, `&` → `&amp;`, `>` → `&gt;`, `<` → `&lt;`, `'` → `&apos;`
- Имена элементов — только строчными буквами
- Максимальный размер файла — 5 МБ
- Корень:
```xml
<?xml version="1.0" encoding="utf-8"?>
<data>
  <cars>
    <car>
      <!-- элементы объявления -->
    </car>
  </cars>
</data>
```

## Обязательные элементы (все категории)

| Тег | Описание | Значения |
|---|---|---|
| `mark_id` | Марка | из каталога Авто.ру |
| `group_id` | Группа/модель | из каталога Авто.ру |
| `color` | Цвет | Бежевый, Белый, Голубой, Желтый, Зеленый, Золотой, Коричневый, Красный, Оранжевый, Пурпурный, Розовый, Серебряный, Серый, Синий, Фиолетовый, Черный (+ варианты металлик) |
| `availability` | Наличие | «В наличии», «На заказ» |
| `custom` | Таможенный статус | «Растаможен», «Не растаможен» |
| `state` | Состояние (для б/у) | «Отличное», «Хорошее», «Среднее», «Требует ремонта» |
| `haggle` | Торг (для б/у) | «возможен», «не возможен» |
| `exchange` | Обмен (для б/у) | «Нет», «Рассмотрю варианты» |
| `run` | Пробег в км (для б/у) | целое > 0 |
| `year` | Год выпуска | целое; б/у не раньше 1970 |
| `price` | Цена | целое > 1500 |
| `currency` | Валюта | RUR, EUR, USD |
| `vin` | VIN или номер шасси | 17 символов, латиница A-Z + цифры 0-9 |
| `wheel` | Расположение руля | «левый», «правый» |
| `engine_volume` | Объём двигателя, см³ | — |
| `engine_type` | Тип двигателя | дизель, бензин, электро, гибрид, дизель-газ, бензин-газ, газ |

## Прицепы (trailer_type) — специфика

| Тег | Обязательность | Описание |
|---|---|---|
| `trailer_type` | обязателен для категории «Прицепы» | см. полный список значений ниже |
| `axis` | опционален | количество осей |
| `brake_type` | опционален | «барабанные», «дисковые» |
| `trail_loading` | опционален | нагрузка на сцепное устройство, кг |
| `loading` | опционален | грузоподъёмность, кг |
| `suspension_chassis` | опционален | «рессора-рессора», «рессора-пневмо», «пневмо-пневмо» |

Готового примера XML для категории «Прицепы» на странице нет (есть только
для автобусов/грузовиков/тягачей/спецтехники) — собирать по аналогии с
примером «Trucks» ниже + поля выше.

## Опциональные элементы (общие)

`credit_discount`, `insurance_discount`, `leasing_discount`,
`tradein_discount`, `max_discount` — скидки; `description` (до 30 000
символов); `with_nds` (true/false); `images` (до 40 JPG, до 20 МБ каждое,
пропорция 4:3); `sale_services` (premium/special/package_turbo);
`unique_id` (до 50 симв., если нет VIN); `gearbox`; `seats`; `engine_power`;
`extras`; `action` (hide/show); `poi_id`; `contact_info`;
`service_auto_apply`; `panoramas`; `badges`; `delivery_info`.

## Прочие справочники значений (найдены на той же странице)

- **Автобусы (`bus_type`):** Вахтовый, Городской, Междугородный,
  Микроавтобус, Пригородный, Специальный, Туристический, Школьный
- **Автопогрузчики (`autoloader_type`):** Боковой погрузчик, Вилочный,
  Вилочный электропогрузчик, Грейферный, Контейнерный, Мини-погрузчик,
  Погрузочно-доставочная машина, Погрузчик-комплектовщик, Телескопический,
  Универсальный, Фронтальный
- **Сельхозтехника (`agricultural_type`):** Валочно-пакетирующая машина,
  Гусеничный трактор, Загрузчик сухих кормов, Измельчитель, Колесный
  трактор, Комбайн, Кормораздатчик, Мини-трактор, Мотоблок, Мульчер,
  Опрыскиватель, Пересадчик деревьев, Подборщик, Пожарный трактор,
  Самоходная газонокосилка, Сеялка, Скиддер, Трелевочный трактор,
  Форвардер, Харвестер
- **Строительная техника (`construction_type`):** ~45 значений (автобетононасос,
  автогрейдер, каток, кран разных типов и т.д. — см. страницу-источник)
- **Бульдозеры (`bulldozer_type`):** Гусеничный, Колесный. Тяговый класс
  (`traction_class`): 3, 4, 6, 10, 15, 25, 35, 50, 75
- **Коммунальная техника (`municipal_type`):** ~19 значений (мусоровоз,
  автовышка, снегоуборочная и т.д. — см. страницу-источник)
- **Экскаваторы (`dredge_type`):** Гусеничный, Драглайн, Земснаряд,
  Карьерный, Колёсный, Мини-экскаватор, Планировщик, Траншейный, Шагающий,
  Экскаватор-амфибия, Экскаватор-погрузчик

## Что ещё нужно для реального запуска

1. **API-токен** (`x-authorization`) от менеджера Auto.ru — пока не запрошен.
2. Хостинг для итогового XML-файла (URL, который Auto.ru будет периодически
   скачивать) — по аналогии с уже работающим Avito-пайплайном.
3. Написать/адаптировать `generate_feed.py` под эту XML-схему (отдельно от
   Avito-схемы — структуры разные).
