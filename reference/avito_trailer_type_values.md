## Марка/модель — валидация непоследовательная, лучше всегда сверять с каталогом по Марке+ТипПрицепа
Steelbear PL-24L прошёл без ошибки по Марке/Модели, хотя в каталоге марок Steelbear числится только с моделями PR-18L/PR-27L/PR-48L (под тем же TypeOfTrailer «Лесовоз (сортиментовоз)»).

**НО 2026-09-05: реальная ошибка на V-Trailer «329D»** — «Неправильно заполнен обязательный параметр — Модель. Значение не найдено.» Каталог под TypeOfTrailer=«Шторный» для Make=«V-Trailer» знает только модели `329`, `332`, `S`, `VTPP31`, `VTPP41` — «329D» (коммерческое обозначение с сайта/дилеров, реальный код `VKRP329D`) там нет, только `329`. Исправлено на `329` — с реальной синхронизацией пока не подтверждено (правка от 2026-09-05, ждём отчёта).

**Вывод пересмотрен: нельзя полагаться на «модель не валидируется» по одному прошедшему прецеденту.** Перед каждой новой записью в `data/` — сверять `model` дословно со списком моделей под нужным `Make` **внутри секции нужного `TypeOfTrailer`** в `avito_trailer_make_model_catalog.xml` (одна и та же марка встречается в файле многократно — под каждым типом прицепа свой отдельный блок `<Make>` с своим набором моделей, см. пример поиска: сначала найти границы `<TypeOfTrailer name="...">...</TypeOfTrailer>`, затем искать `Make` внутри этого диапазона). Коммерческое/маркетинговое название (с сайта производителя, из ПТС) может не совпадать с кодом в справочнике Авито — в описание объявления можно писать реальное имя, а в поле `model` — только точное значение из каталога.

## Ещё не проверено / нет справочника
**Тип подвески (SuspensionChassis)** — этот XML его не содержит (только Make/Model/TypeOfTrailer/TypeOfVehicle). Поставили «Рессорная» по общей отраслевой терминологии по факту ошибки «Зависимая, на продольных рычагах» — не подтверждено реальной успешной синхронизацией на момент записи (см. `pricing/` и историю коммитов для актуального статуса).
