# Папки на профиле Авито — распределение техники

Авито не даёт раскладывать объявления по папкам через API (Автозагрузку) — только руками в интерфейсе профиля. Этот файл — источник истины для того, что должно лежать в какой папке; обновлять при каждом добавлении/снятии объявления.

Три папки: **Новая техника под заказ**, **Б/у техника в наличии**, **Аренда с правом выкупа**.

## Как определять папку

1. **Аренда с правом выкупа** — сверять по VIN со списком в `reference/pricelists/arenda/informaciya-po-tehnike-*.xlsx` (лист «Информация по нашей технике» — это техника в лизинге, продажа объявлением = лидген под аренду-с-выкупом, не буквальная продажа). Только техника из этого списка идёт в эту папку — **не** по признаку «пустое поле `condition`» или наличию слова «аренда» в описании: 2026-09-09 поймали ложное срабатывание именно на этом — у изотермического Kassbohrer (xx246877) тоже пустой `condition` и есть «аренда» в тексте, но по VIN его в списке нет, папка неверная.
2. **Новая техника под заказ** — `condition: "Новое"` + `availability: "Под заказ"` в JSON (`data/*.json` в `avito-feed-trailers/` и `avito-feed/`).
3. **Б/у техника в наличии** — всё остальное активное: `condition: "С пробегом"` + `availability: "В наличии"`, а также позиции с пустым `condition`, которых нет в списке аренды-с-выкупом.

Не забывать, что фид — два разных каталога с раздельными `data/`: `avito-feed-trailers/` (прицепы) и `avito-feed/` (тягачи/самосвалы, сейчас — Shacman).

Раскладывать по факту того, что реально на Авито, не по нашим файлам.
