# Версии API

## Список версий

Ниже приведен список изменений в API от версии к версии.

## Версия 1.0

**23 января, 2026**

 
:   Добавлен новый метод для определения [оценочной стоимости транспортного средства](https://yandex.ru/dev/autoru/doc/ru/reference/stats-partner-predict-by-vin-or-lp.md).

**15 августа, 2025**

 
:   Добавлены новые методы для работы с [чатами](https://yandex.ru/dev/autoru/doc/ru/reference/chats/chats.md).

**3 июля, 2020**

 
:   Добавлены новые методы для работы со [звонками](https://yandex.ru/dev/autoru/doc/ru/reference/all-resources.md).

**18 июля, 2018**

 
:   Добавлены новые [ресурсы](https://yandex.ru/dev/autoru/doc/ru/reference/all-resources.md): аутентификация, личный кабинет дилера и управление объявлениями дилера.

**01 июля, 2017**

 
:   Запущена первая версия.
