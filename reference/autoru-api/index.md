# Введение

Сервис [Авто.ру](https://auto.ru) предназначен для подачи и поиска объявлений о продаже транспорта.

В документе описан программный интерфейс Авто.ру (далее — API Авто.ру, API), который предоставляет возможность работы с базой данных Авто.ру. API можно использовать для получения статистических и справочных данных, основанных на базе объявлений Авто.ру. Для добавления и редактирования объявлений используйте веб-интерфейс.

API будет полезен:

- рекламным агентствам для анализа эффективности объявлений о продаже транспортных средств;
- компаниям, которые занимаются страхованием, лизингом и оценкой стоимости транспортных средств.

Виды данных, которые можно получить с помощью API:

1. Структура каталога транспортных средств Авто.ру (виды транспорта, марки, модели, поколения, конфигурации).
1. Количество активных объявлений в том или ином разделе каталога.
