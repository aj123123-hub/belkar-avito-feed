# Чаты

Вы можете встроить общение в чатах на Авто.ру в свою систему с помощью Webhooks.

Webhook — это механизм оповещения о происходящих в системе событиях.

Используйте Webhooks, чтобы:

- получать сообщения от пользователей Авто.ру. Для этого в личном кабинете дилера добавьте HTTPS URL для приема Webhooks;
- отправлять ответ пользователям Авто.ру из своей системы. Для этого в личном кабинете дилера добавьте идентификационный номер чата в поле [ChatId](*ChatId).

Запросы выполняются по протоколу HTTPS методом POST. Тело запроса представляет собой JSON-объект с информацией о событии.

[*ChatId]: Внешний идентификатор чата. Задается в личном кабинете дилера в поле ChatId при подключении приложения. Должен уникальным образом идентифицировать одного клиента Авто.ру, для которого выполняются запросы.
